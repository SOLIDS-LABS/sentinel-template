# Defects log

Record every error that you meet, when you meet it. Do not wait until the end of a lab. A
short entry is enough.

Each entry has three parts:

- **Symptom:** what you saw. The output, the message, or the wrong number.
- **Cause:** why it happened, and the file and line that caused it.
- **Fix:** what you changed.

At each check, the TA can ask you about any entry.

---

## Template

```
### D-01 · Lab 1 · <a short name>

Symptom   <what you saw>
Cause     <why it happened: the file and the line>
Fix       <what you changed>
```
